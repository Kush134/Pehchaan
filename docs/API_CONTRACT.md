# Frontend API contract
All endpoints use `/api/v1`. Money is numeric INR. All data synthetic. API errors `{detail: string}`. `Idempotency-Key` supported for mutations. Health reports actual provider availability.

- GET `/health`: `{status, demo_mode, database, redis, sarvam:{configured, chat_model, stt_model, tts_model}, payment_provider:'simulated'}`
- GET `/dashboard/summary?days=30`: `{merchant:{id,name,location,category}, period_days, metrics:{revenue,previous_revenue,revenue_change,returning_customers,at_risk_customers,average_basket,transactions,bulk_orders,campaign_redemptions,discount_expense,incremental_gross_profit,active_agents}, revenue_trend:[{date,revenue,transactions}], retention_trend:[{week,returning,new}], segments:[{segment,count,color}], category_revenue:[{category,revenue}], cohorts:[{cohort,values:number[]}], campaigns:Campaign[], recent_events:Event[], recommendation:{title,description,offer_amount,minimum_bill,eligible_customers,projected_gross_profit,projection:true}, provider:{mode,configured}, security:{blocked,eligible}, bulk_performance:[{month,orders,total}]}`
- GET `/customers?segment=All&search=&page=1&page_size=20`: `{items:Customer[],total,page,page_size}`. Customer `{customer_token,merchant_id,total_transactions,lifetime_spend,average_transaction_value,last_transaction_date,first_transaction_date,average_intervisit_interval,previous_30_day_spend,current_30_day_spend,customer_segment,risk_score,estimated_lost_revenue,recency_days,frequency,monetary}`
- GET `/customers/segments`: `[{segment,count,color}]`; GET `/customers/at-risk`: same paginated customers shape.
- GET `/campaigns`: `Campaign[]`. POST `/campaigns` body `{name,target_segment,offer_amount,minimum_bill,start_date,end_date,budget,max_customers,language,ab_test}`. Returns Campaign `{id,name,target_segment,offer_amount,minimum_bill,start_date,end_date,budget,max_customers,language,ab_test,status,created_at,variants:[{id,name,offer_amount,minimum_bill}],stats:{allocated,redeemed,returning_customers,discount_expense,conversion_rate,incremental_gross_profit,control_conversion_rate,treatment_conversion_rate,preliminary,p_value,evidence},assignments:[{customer_token,variant,redeemed}]}`.
- POST `/campaigns/{id}/launch` activates and allocates. POST `/campaigns/{id}/simulate-redemptions` deterministically writes synthetic redemptions/transactions. POST `/campaigns/{id}/stop` stops.
- GET `/catalog/products`: `Product[]` `{id,name,category,unit,selling_price,available_stock,purchase_price,minimum_selling_price,supplier,updated_at}`. POST same fields except id/updated. PATCH `/catalog/products/{id}` editable fields. DELETE `/catalog/products/{id}`. POST `/catalog/import` multipart `file` CSV -> `{imported,products}`. Merchant catalogue route explicitly merchant-role.
- GET `/transactions?page=1&page_size=20`: `{items:[{id,customer_token,amount,category,created_at,campaign_id,simulated}],total,page,page_size}`.
- POST `/firewall/validate` body `{amount,budget?:40000,seller_id?:'seller-a',round_number?:1,operation?:'quote',merchant_approved?:false,buyer_confirmed?:false,quantity_available?:true,delivery_feasible?:true,discount_percent?:0,nonce?,expiry?,signature?}` -> `{id,status,allowed,reasons:string[],rules:[{rule,passed}],amount,budget,created_at}`. No seller floor in response.
- GET `/firewall/audit`: validation response array.
- GET `/events?limit=30`: `Event[]` `{id,type,title,detail,agent,status,created_at,data}`. GET `/events/stream` SSE emits `data: Event` (audit id as event id; Last-Event-ID replay supported).
- GET `/agents/status`: `{agents:[{id,name,status,current_task,last_action,duration_ms,tool_calls}],events:Event[]}`.
- POST `/demo/reset`: `{status:'reset',customers:100,transactions:number}`. Rebuilds all synthetic data.

Workflow/voice routes documented by workflow implementation in `docs/WORKFLOWS_API.md`.

- POST `/transactions/import`: merchant-only multipart `file`, known pseudonymous-token CSV, replay-safe by file hash. Fields `customer_token,amount,category,created_at`. Returns `{imported,simulated:true}`. Future timestamps and unknown tokens are rejected.
- Merchant campaign dates and daily revenue boundaries use Asia/Kolkata. Stored instants remain UTC. Measured incremental gross profit requires treatment n >= 30, control n >= 20, at least 20 returning observations and two-sided Fisher p < 0.05; all other estimates are preliminary.
